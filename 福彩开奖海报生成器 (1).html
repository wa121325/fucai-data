数据来源

填好仓库地址后，工具每次点「一键获取」会直接读取 GitHub 上自动爬取好的 JSON 数据，无需任何 API Key，每天22点自动更新。
没有仓库？见下方"如何配置"指引，5分钟完成，一次配置永久生效。
获取顺序：①GitHub自动数据 → ②直连官方API → ③Claude API中转（需Key）
▸ Claude API Key（直连失败时备用）
Key 只存内存，刷新即清。填好后再点获取按钮使用。
▸ 如何配置 GitHub 自动抓取（5分钟，一次配置永久生效）
第一步：注册 github.com 账号（免费）
第二步：创建新仓库，命名为 fucai-data（设为 Public 公开）
第三步：将下方两个文件上传到仓库根目录（从本工具的下载区获取）：
  • lottery_crawler.py — 爬虫脚本
  • .github/workflows/crawl.yml — 自动执行计划
第四步：仓库 Settings → Actions → General → 勾选 "Allow GitHub Actions to create and approve pull requests" 并保存
第五步：回到本工具，上方填入 你的用户名/fucai-data，点「保存仓库地址」
之后：每天北京时间22:00 GitHub 自动跑爬虫，结果存到 latest.json，本工具直接读取。
